## Installation Guide (macOS)

1. Download the `.dmg` file from the link above.
2. Double-click the downloaded `.dmg` to open it.
3. Drag **Baby Genie** into your **Applications** folder.
4. Launch **Baby Genie** from Applications or Spotlight.

### First-Time Opening on macOS
If macOS Gatekeeper displays a security notice (*"Apple cannot check it for malicious software"*):
1. Open your **Applications** folder in Finder.
2. **Right-click** (or Control-click) **Baby Genie.app** and select **Open**.
3. Click **Open** on the prompt (or go to **System Settings → Privacy & Security** and click **Open Anyway**).
